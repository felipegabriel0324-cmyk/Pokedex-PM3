# 🎮 Pokédex — PM3 

Projeto acadêmico desenvolvido por estudantes de analise e desenvolvimento de sistema, da Uniamerica, com acompanhamento de um mentor.
A proposta é construir uma aplicação web inspirada na Pokédex, aplicando conhecimentos de desenvolvimento front-end e colaboração em equipe.

## 🎯 Objetivo

Praticar os fundamentos do desenvolvimento web por meio de um projeto colaborativo, conectando os conteúdos estudados em sala de aula à construção de uma aplicação.
Os objetivos de aprendizagem incluem:
Estruturar páginas com HTML.
Estilizar a interface com CSS.
Desenvolver interações com JavaScript.
Organizar os arquivos do projeto.
Utilizar Git e GitHub para versionamento e colaboração.
Desenvolver autonomia, comunicação e resolução de problemas. 

## 🚧 Status do projeto 

Em desenvolvimento. 
Atualmente, o projeto conta com a estrutura inicial da página, o cabeçalho estilizado, o logotipo, um campo de pesquisa na interface, cards de pokemons e paginação
A lógica de pesquisa, filtro, favoritos e a aba minha pokedex esta feita.
Falta adicionar informações extras ao interagir com o card de cada pokemon.

## 🛠️ Tecnologias 

- **HTML5:** estrutura da página.
- **CSS3:** apresentação visual da interface.
- **JavaScript:** linguagem prevista para implementar as interações.
- **Git e GitHub:** versionamento e colaboração.
